# 스내피즘 IP 배포 자동화

지라 배포건을 감지해 데이터·가격·이미지·순서를 자동 조립하고 1단계 검수 등록까지 처리하는 자동화.

## 현재 상태
- **Owner:** 조문배 (개발 · 운영 · 기획 전부)
- **상태:** 운영(수동 트리거) — 1·2·3단계 실서버 검증 완료 (2026-07-02 CANDIP-29106 / 2026-07-09 BNK FEARX 페어 / 2026-07-13 이민혁(HUTA) 한국·중국)
- **최초 배포:** 2026-07-02 (앱 배포 버튼으로 실등록)
- **배포 실행:** 1단계=슬랙 📝1단계 등록 버튼(폴링이 리소스완료 티켓 게시)/CLI(→TEST 맵핑) / 2단계=슬랙 🚀배포(한국 7국→검수완료) / 3단계=슬랙 🇨🇳중국(전체 등록→배포완료)
- **다중상품:** 1프레임 여러 상품(포토카드 6종 등) 지원 — 파일명 순번(연도 오인 방지)·캐릭터명(앞면 접미부, 풀문 A/B 보존)·앞뒷면 페어링 자동, 상품 영문명 없으면 상품 한국어명
- **중국 대응:** 소속=getByText 클릭, 날짜=fill(), 이미지=업로드 완료 대기(45s), 매장 국가=실제요소 클릭, 이름 중복 시 한/영 동시 공백
- **STG 테스트:** `run-stg-test.cmd`로 STG(한국 stgadmin / 중국 stage-admin)에서 검증(prod 무손상). `--deploy-stage2/3`, `--no-jira`(지라 생략), `--force-cn`(중국 강제). STG는 국가/매장/카테고리가 prod와 달라 2단계는 스킵, 3단계는 --force-cn.
- **실행 주기:** scheduler.js 폴링 5분 (무인 1단계는 DRY-RUN 준비중)
- **알림 채널:** Slack (SLACK_CHANNEL, 토큰 설정 시)
- **사용 봇·계정:** 어드민 ansqo34 / 지라·Claude 비전 팀 토큰 / Slack 봇(미설정)

## 실행
```
node src/integrations/run.js --list           # 대상 조회
node src/integrations/run.js --issue CANDIP-X  # 특정 건 dry-run
node src/integrations/run.js --issue CANDIP-X --live  # 실제 등록
npm run poll                                   # 무인 폴링(DRY-RUN)
npm run poll -- --live                         # 무인 실제 가동
```
