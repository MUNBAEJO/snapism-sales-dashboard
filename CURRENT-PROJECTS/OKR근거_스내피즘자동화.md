## 🎯 Objective
**지라-구글드라이브 연동 기반 스내피즘 업로드·스케줄링 자동화율 80% 달성**
파이프라인: 지라 링크 연동 → 구글 드라이브 리소스 자동 다운로드 → 지라 일정 기반 자동 스케줄링·업로드

### 구축된 파이프라인 (Objective 실현)
| 단계 | 자동화 내용 |
|---|---|
| **지라 감지** | 트리거 상태(리소스 업로드 완료) 티켓 자동 감지 · 오픈일 D-1~D+14 필터 · 워크타임 5회 슬랙 알림 |
| **드라이브 자동 다운로드** | 지라 본문 드라이브 링크 → Google Drive API(서비스계정) → 이미지 자동 수집·분류(상품/썸네일/목업/차수/팀) |
| **자동 스케줄링** | `/snapadd` 예약(오픈일 00시 무인 실행) · status-sync(오픈일 도래 시 지라 "배포완료→송출중", 기한종료 시 "송출중→완료" 자동 전환, 매일 예약작업) |
| **자동 업로드** | 한국 어드민(1·2단계)·중국 어드민(3단계) Playwright 자동 등록 — IP/컬렉션/상품/국가/매장/가격/판매기간 |
