🎯 해결하는 문제

  • 스내피즘 KR·CN 어드민에서 국가별 매출을 따로 접속해 수동으로 확인해야 했음
  • KRW·CNY·JPY·IDR·TWD·THB·HKD·MYR 8개 통화 환산을 매번 수작업으로 계산해야 했음
  • IP별·매장별·시간대별 매출 비교 수단이 없었음
  • 쿠폰 결제 건이 매출 집계에서 누락돼 정산 기준 금액 파악이 어려웠음

⚙️ 동작 방식

  1. Windows 작업 스케줄러(snapism_daily)가 매일 오전 09:00 crawler.py 자동 실행 — PC 재부팅 후에도 누락 시 즉시 보충 실행
  2. Playwright가 KR·CN 어드민에 로그인 후 전날 날짜로 필터 설정 → CSV 자동 다운로드
  3. ingest.py가 raw CSV를 data/master.csv에 누적 합산 (날짜+주문번호 기준 중복 제거)
  4. 실시간 환율(fawazahmed0/currency-api)을 매일 자동 갱신해 KRW 환산에 반영
  5. Streamlit 대시보드(포트 8503)에서 날짜·국가·매장·IP 필터로 실시간 조회
